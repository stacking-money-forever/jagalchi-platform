# Contract pin

The checked-in `contract/openapi.json` is generated by the canonical standalone
`jagalchi-api` repository. Its SHA-256 pin is:

`4eac6f4879393e5561a017f86533db0bd7998e047d619ee1c263c5293a6c968d`

Update procedure: regenerate the API artifact, replace the snapshot, update the hash
in `scripts/check-contract-hash.mjs`, run `pnpm generate`, and compile both consumers.
CI fails closed when the snapshot and pin differ.
